# House Edge

An incremental game about a stranded delivery driver, a gas station in the desert and a rigged pachinko machine. Play it for fuel, learn how it cheats, then buy it.

**[Play House Edge](https://foggysteam.github.io/house-edge/)**

It runs in the browser, on a desktop or a phone. Nothing to install. It has an ending: about 3 to 5 hours.

Your progress is saved in your browser. The save screen in the game gives you a code to back it up or move it to another browser.
